# Evidence Store

This directory is a simple, file-based starting point. It is not a database.
YAML is used because people can read and review it directly.

```text
Claim
  ↓ supported by
Evidence
  ↓ generated by
Experiment / source
  ↓ linked to
Code / configuration / result
  ↓
Human review
```

`example-experiment.yaml` records the information needed to identify and repeat
an experiment. `example-claim.yaml` shows how a draft claim links back to that
record. `agent-demo.yaml` supplies the bounded question and two local records
used by the from-scratch agent loop. All three are illustrative and explicitly
unreviewed; they must not be cited as completed scientific findings.

Use stable identifiers and project-relative paths where practical. Do not copy
sensitive data into these files. A record should be changed to a reviewed state
only by a named person who has inspected the underlying sources or results.
